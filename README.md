# 💻 TechNews Today - Desafio CSS 🚀

Este repositório contém a resolução do desafio da **Aula 10**, proposto pelo professor **Andre Luis Denani**. O objetivo do projeto foi aplicar conceitos avançados de CSS moderno para estilizar um portal de notícias tecnológico dinâmico, elegante e totalmente responsivo.

O foco principal do desafio foi criar um layout robusto escrevendo um código CSS limpo, otimizado e limitado a no máximo 50 linhas, sem alterar a estrutura do HTML fornecido e sem o uso de frameworks ou JavaScript.

---

## 📸 O Projeto
O portal **TechNews Today** apresenta uma interface moderna com foco na experiência do usuário (UX), destacando-se pelos seguintes elementos visuais e estruturais:
* **Header de vidro fosco** (efeito Glassmorphism) fixo no topo da página.
* **Título principal com efeito degradê** marcante.
* **Layout inteligente em duas colunas** posicionando o vídeo e a newsletter lado a lado.
* **Adaptabilidade total** para telas de smartphones.

---

## 📋 Checklist do Desafio (Critérios de Avaliação)

Todos os requisitos exigidos para a entrega foram implementados com sucesso:

- [x] **Glassmorphism:** Efeito de vidro fosco refinado utilizando a propriedade `backdrop-filter`.
- [x] **Gradiente no texto:** Título estilizado com degradê moderno.
- [x] **CSS Grid Layout:** Estruturação alinhada e precisa do vídeo e da newsletter lado a lado.
- [x] **Header Fixo:** Navegação superior persistente utilizando `position: sticky`.
- [x] **Responsividade (Mobile First/Media Query):** Adaptação perfeita do layout para visualização em celulares 📱.
- [x] **Código Limpo:** Estilização completa realizada em **no máximo 50 linhas de CSS**.
- [x] **Zero Frameworks:** Desenvolvido puramente com CSS3 nativo, sem JavaScript e sem alterar o HTML.
